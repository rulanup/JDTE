# JDT Extras 0.6.0.3

Released September 30, 2026. This feature release introduces the Upgrade Storage and Energy Overload Upgrade, along with greenhouse crop scaling improvements, for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.0.3.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.0.3.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.0.2 or 0.6.0.2-fix1 requires no configuration or world changes; machine settings and block entities carry over unchanged.

## Highlights

### Upgrade Storage (`jdte:upgrade_storage`)

- **Dedicated Handheld Storage**: Added the Upgrade Storage item, a portable case designed exclusively for storing JDTE and Just Dire Things upgrade cards and items.
- **4×5 Slot Grid (20 Slots)**: Provides 20 dedicated slots arranged in a clean, pixel-perfect 5-column by 4-row layout with custom GUI textures and hover item summaries.
- **64 Stacking**: Upgrades stored inside stack up to 64 per slot, overcoming standard single-item stack limitations.
- **Smart Quick-Move & Anti-Nesting**: Intelligent Shift-click support merges matching cards up to 64 when depositing and transfers one by one into player inventory when withdrawing. Nested upgrade storages and non-upgrade items are strictly prohibited.
- **Item Capability & Persistence**: Employs independent `ItemContainerContents` data components for seamless saving without vanilla shulker box count validation conflicts, and exposes `Capabilities.ItemHandler.ITEM` for external automation.

### Energy Overload Upgrade (`jdte:energy_overload_upgrade`)

- **Unlimited Energy Transmission**: Dedicated upgrade for Advanced and Extended Energy Transmitters (limit 1).
- **Removes Transfer Caps**: Completely bypasses single-batch, per-tick transfer budgets, and ME energy extraction caps, allowing transmitters to dump unlimited energy into target blocks and bound player inventories within a single tick.

### Greenhouse Crop Growth Uniformity Fix

- **Consistent Growth Scaling**: Fixed an issue where vanilla crops and Mystical Agriculture crops scaled differently with upgrades and tick intervals in the Greenhouse.
- Both crop categories now share unified execution scaling and upgrade multiplier application.
