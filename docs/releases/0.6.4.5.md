# JDT Extras 0.6.4.5

Released October 17, 2026. Refreshes 14 item textures and extends the optional legacy resource pack with the displaced textures and state models.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install `jdte-0.6.4.5.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.4.5.jar`; use matching JDTE and JDTE-AE versions on both sides with AE2 19.2.17 or newer in the 19.x series. The `-sources.jar` files are for development. SHA-256 checksums are included in `SHA256SUMS-0.6.4.5.txt`.

## Optional legacy resource pack

- Displaced local textures, embedded copies of previously borrowed JDT textures, and 23 previous item/state models are included in the bundled legacy pack.
- Earlier pack contents are retained. The older Time Fluid Catalyst texture is archived under `assets/jdte/textures/item/archive/`; the active legacy texture restores the appearance immediately before this update.
- Client startup exports the pack to `resourcepacks/JDTE-Legacy-Textures.zip`. It is not enabled automatically, and an existing file is not overwritten.
- To refresh an existing exported pack, back it up, remove the old file, and restart the client. Enable the newly exported pack in the Resource Packs screen to restore the previous appearance.

The uploaded PNGs, model references and legacy ZIP integrity were checked. In-game appearance has not been verified.
