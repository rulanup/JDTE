# JDT Extras 0.6.0.2-fix1

Released September 27, 2026. This is a hotfix release for the 0.6.0.2 line, for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.0.2-fix1.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.0.2-fix1.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.0.2 requires no configuration or world changes; machine settings and block entities carry over unchanged.

## Highlights

### Fixed — Extended Experience Holder UI Layout

- Resolved an issue where `ExtendedExperienceHolderBE` erroneously implemented `FilterableBE`. This caused `BaseMachineScreen` to generate duplicate allowlist and NBT comparison toggle buttons that directly overlapped with the "Owner Only" (Steve head) and "Target Level" buttons, as well as 9 non-functional filter slots that intersected through the rendered experience progress bar.
- Removed the filter interface and unused filter data from `ExtendedExperienceHolderBE`, restoring a clean UI layout and proper experience progress bar rendering matching base Just Dire Things behavior.
