# JDT Extras 0.6.5.4

Makes Curios API an optional dependency rather than an undeclared hard requirement, resolving startup crashes when Curios is absent while preserving full Curios functionality when installed.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Curios API (Optional) | 9.0.0 or newer |
| Java | 21 |

Install `jdte-0.6.5.4.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.5.4.jar`; use matching JDTE and JDTE-AE versions on both sides with AE2 19.2.17 or newer in the 19.x series. The `-sources.jar` files are for development. SHA-256 checksums are included in `SHA256SUMS-0.6.5.4.txt`.

## Changes

- **Curios Optional Dependency**: Declared Curios API as an optional dependency in `neoforge.mods.toml` (`ordering="AFTER"`).
- **Decoupled Big Fluid Tank**: Removed direct `ICurioItem` implementation from `BigFluidTankItem` to eliminate `NoClassDefFoundError` during class loading when Curios is absent; dynamically registers Curios item behaviors at runtime when Curios is loaded.
- **Isolated Large Portable Container Menus**: Extracted Curios API resolution into `LargePortableContainerCuriosIntegration` under `ModList.get().isLoaded("curios")` guards, preventing class verification failure when opening containers without Curios.
- **Guarded Setup & Sources**: Wrapped Big Fluid Tank login listeners and curio registrations in ModList checks; made equipment and storage source checks dynamic.

## 中文说明

将 Curios API 依赖全面改为可选依赖，修复未安装 Curios 时的类加载崩溃问题，并在安装 Curios 时完整保留全部饰品栏功能：

- **可选依赖声明**：在 `neoforge.mods.toml` 中明确声明 `curios` 为可选依赖。
- **大型流体储罐解耦**：`BigFluidTankItem` 移除直接实现的 `ICurioItem` 接口，改为在检测到 Curios 时通过 `CuriosApi.registerCurio` 动态注册饰品行为。
- **便携容器界面隔离**：将大型便携容器界面的 Curios API 调用隔离至独立集成类 `LargePortableContainerCuriosIntegration`，未安装 Curios 时安全回退，防止合成方法触发类验证崩溃。
- **生命周期保护**：主类登录事件监听与行为注册均增加 `ModList.get().isLoaded("curios")` 判断保护，装备与存储源探测改为安全动态调用。

主模组与配套可选 JDTE-AE 均更新为 **0.6.5.4**，客户端与服务端请使用匹配版本。
