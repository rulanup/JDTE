# JDT Extras 0.6.3.3

Released October 10, 2026. This feature and maintenance release expands Bio Factory output product stacking to 6,400,000 under the Ultimate Capacity Upgrade and synchronizes Bio Factory Ultimate Overclock speed multipliers with the GUI, for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.3.3.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.3.3.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.3.2 requires no configuration or world changes; machine settings, inventories, and block entities carry over unchanged.

## Highlights

### Bio Factory Stacking Expanded to 6,400,000 (`jdte:bio_factory`)

- **6.4 Million Item Slot Limit**: Installing the Ultimate Capacity Upgrade (`jdte:ultimate_capacity_upgrade`) now scales the output slot stack limit for the Bio Factory to **6,400,000** items per slot.
- **Compact Count Rendering**: Bio Factory GUI output slots render scaled count labels matching the Greenhouse, preventing text overflow.
- **Automation and Export Compatibility**: Fully integrated with internal slot handlers, shift-click transfers, hopper/pipe extraction, and Advanced AE Output extraction queues.

### Bio Factory Ultimate Overclock GUI & Multiplier Synchronization

- **Locked Overclock Multiplier Synchronization**: Aligned the Bio Factory's speed calculation with Greenhouse standards. Installing an Ultimate Overclock Upgrade locks `getMultiplier()` and `getMaxSelectableMultiplier()` to 640 (standard Overclock locks to 64), resolving the discrepancy where the GUI previously remained at 1~64 while internal processing ran at 640x.
- **Interactive Number Button Sync**: The GUI speed multiplier button displays 640 in real time and automatically updates via ContainerData synchronization. Removing the upgrade smoothly restores selectable multiplier controls.
