# JDT Extras 0.6.5.6

Brings the tiered solar panels back from JDTE-MoreContent and adds real-server GameTests to the release pipeline.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Curios API (Optional) | 9.0.0 or newer |
| Java | 21 |

Install `jdte-0.6.5.6.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.5.6.jar`; use matching JDTE and JDTE-AE versions. SHA-256 checksums are included in `SHA256SUMS-0.6.5.6.txt`.

## Changes

- **Tiered solar panels**: Concentrated, Singularity, Stellar Fusion, Dimensional Collapse and Creative solar panels are back. Each tier generates 4x the previous one, gains up to 2x from same-tier neighbours, scales with build height, and pushes FE into adjacent energy receivers. Panels only export energy; they do not accept external input.
- **Testing**: Added JUnit coverage for solar generation, storage and transfer, plus NeoForge GameTests (`runGameTestServer`) that place every panel tier in a real world and check its block entity and energy capability. Releases now run these GameTests before publishing.

## 中文说明

- **分级太阳能板回归**：聚能、奇点、恒星聚变、维度坍缩和创造太阳能板重新加入。每一级发电量是上一级的 4 倍，相邻同级面板最多带来 2 倍加成，发电量随建筑高度变化，并自动向相邻的能量接收方输出 FE。面板只输出能量，不接受外部输入。
- **测试**：新增太阳能发电、储能和输出的 JUnit 测试，以及 NeoForge GameTest（`runGameTestServer`），在真实世界里放置每一级面板，检查方块实体和能量能力。发布流程现在会先跑这些 GameTest。
