# JDT Extras 0.6.5.8

Fixes the Fluid Mixer's catalyst slot, where the visible slot frame and the real slot were offset from each other.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Curios API (Optional) | 9.0.0 or newer |
| Java | 21 |

Install `jdte-0.6.5.8.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.5.8.jar`, published as an additional file of this release; use matching JDTE and JDTE-AE versions. SHA-256 checksums are included in `SHA256SUMS-0.6.5.8.txt`.

## Changes

- **Fluid Mixer catalyst slot**: the machine panel is drawn in JDT's widened top section, which sits `extraWidth / 2` pixels left and 26 pixels above the menu origin. The catalyst slot was still registered at menu-origin coordinates, so the frame the player sees (and whose tooltip promised a slot) sat 30 px right and 26 px below the clickable slot — clicking it inserted nothing. The slot now uses the same origin as the drawn frame, matching the fix already shipped on the Forge 1.20.1 line.
- Applies to the Advanced and Extended Fluid Mixer alike; no recipe, capacity or behaviour changes.
