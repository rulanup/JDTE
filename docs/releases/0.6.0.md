# JDT Extras 0.6.0

Released September 25, 2026. This is the formal 0.6.0 release for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.0.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.0.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

## Highlights

### AE2 full-grid acceleration

The independent JDTE-AE addon is now part of the 0.6.0 release. It advances complete AE2 Grid lifecycles for covered online and fully booted nodes, including Molecular Assemblers, crafting services, Pattern Providers, and compatible addon devices. Multiple covered nodes on one Grid are deduplicated, lifecycle scopes are cleaned up in `finally`, and the logical tick bridge preserves monotonic timestamps without modifying AE2's global counter. ExtendedAE remains a development verification dependency, not a published hard dependency.

### Bio Factory output safety

Bio Factory production now persists a completed output transaction until all item and fluid outputs fit. Costs and consumed inputs are committed only when the output commit succeeds, and pending output survives block-entity save/load. This prevents duplicated consumption and lost results when output capacity is temporarily blocked or the world restarts between completion and insertion.

### Extended Gel Generator conversion

The Extended Upgrade now recognizes the Advanced Gel Generator and converts it to the Extended Gel Generator while preserving the normal upgrade conversion flow.

### Loot Fabricator memory stability

Each generated loot entity is explicitly discarded after the loot roll completes. Together with the stable per-level FakePlayerFactory identity and `finally` cleanup of the temporary Looting weapon, continuous and accelerated production no longer retains one temporary living entity per roll.

### Ultimate Portal Gun dimension picker

The manual destination editor now opens a dedicated dimension selection screen instead of cycling through dimensions with one button. Dimensions are filtered through the existing teleport blacklist, sorted by full `namespace:path`, and displayed eight per page with previous, next, back, and Escape navigation. Returning to the editor preserves unsaved name and coordinate fields; selecting a dimension changes only the pending destination until Save is pressed.

## Documentation

Current-version metadata, README files, KubeJS guides, developer references, and bilingual in-game guide pages now report 0.6.0. The `0.6.0-pre6` release notes remain available as the historical prerelease record.

## Validation

The release was validated with the Gradle Java compilation, the full test task, the dimension-paging regression tests, and the main and JDTE-AE JAR/source-JAR build tasks.
