# JDT Extras 0.6.4.3

Released October 14, 2026. Adds the Charged Lightning Rod, weather control through a dedicated upgrade, two machine-specific overclock tiers, and independent lightning rendering and sound controls.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install `jdte-0.6.4.3.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.4.3.jar`; use matching JDTE and JDTE-AE versions on both sides with AE2 19.2.17 or newer in the 19.x series. The `-sources.jar` files are for development. SHA-256 checksums are included in `SHA256SUMS-0.6.4.3.txt`.

## Charged Lightning Rod

- New machine: `jdte:charged_lightning_rod`, with FE input, a 10,000,000 FE base buffer, crafting recipe, and upgrade slots.
- Requires a thunderstorm by default. Installing one Thunderstorm Upgrade (`jdte:thunderstorm_upgrade`) permits operation in other weather and dimensions.
- Leave the block above the machine clear for its vanilla lightning rod, or supply a vanilla lightning rod there.
- Generates full vanilla `LightningBolt` entities with damage, fire, lightning events, and the `ae2lt.natural_weather_lightning` marker used by AE2 Lightning Tech 2.1.2-beta3. These are machine-generated strikes carrying the compatibility marker.
- Energy is charged only when each lightning entity is successfully added to the world. Insufficient FE reduces the number of strikes produced.

| Mode | FE per strike | Maximum rate |
| --- | ---: | --- |
| Default | 10,000 | 1 strike every 10 seconds |
| Overclock | 40,000 | 5 strikes per tick |
| Ultimate Overclock | 100,000 | 50 strikes per tick |

Full-rate Ultimate Overclock requires 5,000,000 FE per tick. The machine keeps its own per-world-tick batch limit so the common overclock ticker does not multiply these rates again.

## Machine controls

The machine screen shows the current FE cost, rate, and weather readiness. Two independent buttons control lightning rendering (including sky flashes) and thunder/impact sounds. Settings persist and sync to clients; gameplay effects and AE2LT recognition remain active when presentation is disabled.

The Machine Settings Copier supports both presentation switches without copying stored FE or runtime work state.

## Validation

The complete Gradle build passed on Java 21: all 644 automated tests passed (611 main-mod tests and 33 JDTE-AE tests), with no failures or skips. Tests include upgrade compatibility, settings persistence and copying, and live lightning-Mixin loading. Release JAR metadata, matching addon dependencies, resource references, and archive integrity were checked. Client GUI interaction and combined AE2LT gameplay have not been tested in-game.
