# JDT Extras 0.6.5.7

Makes the AE Output Upgrade work on the Advanced Item Collector and adds a compile gate plus automatic CurseForge publishing to the release pipeline.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Curios API (Optional) | 9.0.0 or newer |
| Java | 21 |

Install `jdte-0.6.5.7.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.5.7.jar`, published as an additional file of this release; use matching JDTE and JDTE-AE versions. SHA-256 checksums are included in `SHA256SUMS-0.6.5.7.txt`.

## Changes

- **Advanced Item Collector honours the AE Output Upgrade**: the card could be installed but never did anything, because the collector has no internal buffer to drain. Each collected stack is now offered to the network bound to the installed card first (whole-stack, atomic). When the network accepts it, no facing container is needed; when the card is missing, unlinked, or the network accepts only part of the stack, collection falls back to the facing container and the existing ME direct-insertion path. Both output tiers behave the same, and only one output card can be installed.
- **Documentation**: the GuideME and Patchouli pages for the collector now list the AE Output upgrades and describe the insertion order instead of claiming the machine only accepts Range and Filter.
- **Build pipeline**: every push and pull request now compiles both mods in CI, and tagged releases publish `jdte` plus the JDTE-AE addon to CurseForge automatically.

## 中文说明

- **高级物品拾取器支持 AE 输出升级**：此前升级卡能装进去但毫无作用，因为拾取器本身没有可抽取的内部缓存。现在每一叠收集到的物品会先整叠、原子地送入升级卡绑定的网络；网络能一次接收时不再需要朝向容器；未装卡、未绑定或网络只能接收一部分时，回退到朝向容器与既有的 ME 直传路径。两种 AE 输出升级行为一致，且只能安装一张。
- **文档**：拾取器的 GuideME 与 Patchouli 页面改为列出 AE 输出升级并说明插入顺序，不再声称只能安装范围与过滤升级。
- **构建流程**：每次 push 与 PR 都会在 CI 编译两个 mod；打标签发布时会自动把 `jdte` 与 JDTE-AE 附加组件发布到 CurseForge。
