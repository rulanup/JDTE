# JDT Extras 0.6.5.5

Fixes the Large Pocket Generator stalling when powered by a Large Fuel Canister filled with high-tier JDT coal (for example 800x or 1600x burn-speed fuels).

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Curios API (Optional) | 9.0.0 or newer |
| Java | 21 |

Install `jdte-0.6.5.5.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.5.5.jar`; use matching JDTE and JDTE-AE versions. SHA-256 checksums are included in `SHA256SUMS-0.6.5.5.txt`.

## Changes

- **Large Pocket Generator high-tier fuel**: The Large Fuel Canister multiplies the fuel burn-speed multiplier by 10, so high-tier fuels produced a combined multiplier larger than the burn time of one canister operation. The burn counter rounded down to 0 and the generator never started. The fuel multiplier is now clamped so each operation lasts at least one tick, keeping total FE per operation unchanged. Ordinary fuels (coal, blaze rods) are unaffected.
