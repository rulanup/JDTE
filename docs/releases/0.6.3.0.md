# JDT Extras 0.6.3.0

Released October 6, 2026. This feature and maintenance release introduces the Mineral Extractor JEI integration and network synchronization, modded ore world-generation recognition improvements, the Ultimate Overclock Upgrade, the Ultimate Capacity Upgrade, 32768X acceleration for the Ultimate Time Wand, and complete GuideME and Patchouli in-game documentation for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.3.0.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.3.0.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.2.0 requires no configuration or world changes; machine settings and block entities carry over unchanged.

## Highlights

### Mineral Extractor JEI Integration & Network Synchronization

- **Dedicated JEI Recipe Category (`jdte:mineral_extractor`)**: Fully integrated into Just Enough Items (JEI) and Recipe Viewers. Players can now browse every surveyed biome, view extractable ores, inspect base drop probabilities, and view smelting outputs directly in JEI.
- **Bi-directional Network Synchronization**: Server-side biome mineral survey indices are synchronized to clients via `MineralSurveySyncPayload` upon login and whenever `/reload` runs, populating the client-side `MineralSurveyClientCache` and keeping JEI views completely accurate on multiplayer servers.
- **Screen Click Areas**: Machine GUI arrow and survey slot areas link directly to the Mineral Extractor JEI category.

### Modded Ore Feature Detection & Compatibility

- **Mekanism & Modded Ore Support**: Overhauled `MineralFeatureAnalyzer` to recognize custom configured ore features, including Mekanism's `ResizableOreFeatureConfig` (such as Osmium, Tin, Lead, and Uranium ore veins), vanilla deepslate replacement rules, and custom BiomeModifiers.
- **Robust Codec & Reflection Fallback**: Configured features without standard `OreConfiguration` unpack target lists using reflection and dynamic JSON Codec serialization, ensuring all modded ore blocks are properly detected across biomes without missing entries.

### Ultimate Overclock Upgrade (`jdte:ultimate_overclock_upgrade`)

- **Extreme Machine Speed**: Limit 1 per machine. Locks machine operational delay to 1 tick and executes 10 iterations per tick at 50x power consumption.
- **Ultimate Time Wand Synergy**: Can be applied to the Ultimate Time Wand through crafting or smithing. Once installed, it increases the wand's maximum acceleration capability from 2048X up to 32768X ($2^{15}$).

### Ultimate Capacity Upgrade (`jdte:ultimate_capacity_upgrade`)

- **Extreme Machine Storage**: Limit 1 per machine. Functions as a 50x capacity upgrade multiplier, massively expanding FE energy storage, fluid tank capacities, and maximizing output inventory space in supported JDTE machines.

### GuideME & Patchouli In-Game Documentation

- **Comprehensive Guides**: Added detailed documentation entries in both English and Simplified Chinese across GuideME and Patchouli guidebooks for the new Ultimate Overclock Upgrade, Ultimate Capacity Upgrade, and the updated Ultimate Time Wand acceleration capabilities.
