# JDT Extras 0.6.4.1

Released October 13, 2026. This texture and decoration update refreshes JDTE item textures, provides an optional legacy texture pack, and adds three decorative fumo blocks with visibility disabled by default.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install `jdte-0.6.4.1.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.4.1.jar`; install matching JDTE and JDTE-AE versions on both sides when using it. The `-sources.jar` files are for development and do not belong in the mods folder. SHA-256 checksums are provided in `SHA256SUMS-0.6.4.1.txt`.

## Refreshed item textures and optional legacy pack

- Updated upgrade cards, tools, factory packages and boss essence textures, including animated essence assets.
- The original textures are bundled as a separate resource pack. Client startup exports it to `resourcepacks/JDTE-Legacy-Textures.zip` inside the game directory.
- The legacy pack is not enabled automatically. Enable it manually in the Resource Packs screen to restore the previous appearance.
- An existing `JDTE-Legacy-Textures.zip` is preserved rather than overwritten.

## Optional decorative fumo blocks

| Block | Registry ID |
| --- | --- |
| Xingye / 星野玩偶 | `jdte:xingye_fumo` |
| Yunyouwan / 云游玩玩偶 | `jdte:cainiaoyo_fumo` |
| Maiqilin / 麦淇淋玩偶 | `jdte:maiqilin_fumo` |

The dolls face the player when placed, support four horizontal directions, and drop themselves when broken. They have no crafting recipes and do not generate naturally.

The dolls are hidden from creative tabs, creative search and JEI by default. To display them, enable **Show Fumo Dolls / 显示玩偶** in JDTE's Content Settings, or edit `config/jdte/jdte.toml` in the client game directory:

```toml
[jdte.content]
showFumoDolls = true
```

Reopen the world after changing this setting. Disabling visibility preserves dolls already placed or held in an inventory.

## Validation

Built and tested on Linux with Java 21 and the project's Gradle 9.0.0 Wrapper. Automated tests cover doll placement direction and shapes, resource references, default visibility, JEI integration and legacy-pack export. In-game visual validation has not been performed.
