# JDT Extras 0.6.4.2

Released October 13, 2026. This compatibility release fixes the mineral-scanning exception reported in [Issue #21](https://github.com/rulanup/JDTE/issues/21), which could prevent players from joining worlds with Infinity 2.7.3 installed.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install `jdte-0.6.4.2.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.4.2.jar`; install matching JDTE and JDTE-AE versions on both sides when using it. The `-sources.jar` files are for development and do not belong in the mods folder. SHA-256 checksums are provided in `SHA256SUMS-0.6.4.2.txt`.

No configuration or world migration is required.

## Infinity world login fix

- Infinity 2.7.3's runtime-only `CenterProximityPlacementModifier` reports the vanilla `RARITY_FILTER` type. Its codec therefore tries to cast that custom modifier to `RarityFilter` when JDTE inspects placement metadata.
- JDTE now handles runtime exceptions at the individual modifier's metadata boundary. An incompatible codec no longer aborts the complete mineral index rebuild during player login.
- Ore entries and other modifiers' count/height estimates are retained, and disabled/retrogen feature checks still apply. Unsupported placement metadata is ignored for estimation; the resulting ore profiles remain marked as estimated.
- The change affects JDTE's survey analysis and does not alter Infinity's world-generation behavior.

## Validation

The reported `ClassCastException` was reproduced in regression tests before the fix. Tests also cover incompatible count codecs, modifier order, following ore features, disabled/retrogen filtering and valid vanilla rarity filters.

The full build and all 639 automated tests passed on Linux with Java 21 and the project's Gradle 9.0.0 Wrapper. The modifier's type was verified against the official Infinity 2.7.3 NeoForge artifact. An existing Infinity world has not been tested in-game.
