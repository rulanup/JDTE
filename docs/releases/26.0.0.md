# JDT Extras 26.0.0

The first JDT Extras release for Minecraft 26.1.2. The version number now follows the Minecraft calendar version. This release ports the 0.6.5.4 feature set to NeoForge 26.1.2 and Java 25, and redraws several models.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 26.1.2 |
| Mod loader | NeoForge 26.1.2.126 or newer (below 26.2) |
| Just Dire Things | 1.6.11 or newer |
| Curios API (Optional) | 15.0.0 or newer |
| Applied Energistics 2 (Optional) | 26.1.13-beta or newer |
| Java | 25 |

Install `jdte-26.0.0.jar` on the client and the server. The optional full-grid AE2 addon is `jdte-ae-26.0.0.jar`. Use the same JDTE and JDTE-AE versions on both sides, with AE2 26.1.13-beta or newer. The `-sources.jar` files are for development only. SHA-256 checksums are in `SHA256SUMS-26.0.0.txt`.

Worlds from Minecraft 1.21.1 are not an officially supported upgrade path. Back up your world before you try one.

## Changes

- **Port to Minecraft 26.1.2**:
  - The main mod and JDTE-AE now build against NeoForge 26.1.2.126, Java 25, Just Dire Things 1.6.11 and AE2 26.1.13-beta.
  - Fluid, item and energy transfer use the native NeoForge transfer APIs.
  - Machine save data uses `ValueInput`/`ValueOutput`.
  - Item models use the new client item definitions.
- **Redrawn models (Blockbench)**:
  - Thunderstorm Upgrade.
  - Charged Lightning Rod: its copper top socket lines up with a vanilla lightning rod placed above it.
  - The three-by-three-by-two Large Greenhouse, Life Synthesis Vat and Large Mineral Extractor, in the Eclipse Alloy, Blazegold and Celestigem palettes used by the smaller machines.
- **Integrations not yet available**:
  - Botany Pots and Draconic Evolution have no 26.1.2 builds yet, so these integrations are left out of this release:
    - Botany Pots Greenhouse crops.
    - Chaos Guardian loot.
    - Stabilized Spawner and Fusion energy.
  - Their code is kept and will return when upstream versions are available.
  - Just Dyna Things for 26.1.2 no longer ships Echoing Buddings. The Crystal Incubator handles JDT time buddings through tags.
- **Release workflow**: tags may now use the three-part `v26.0.0` form.

## 中文说明

JDT Extras 首个 Minecraft 26.1.2 版本，版本号改为跟随 Minecraft 日历版本。本版将 0.6.5.4 的全部功能移植到 NeoForge 26.1.2 / Java 25，并重绘了部分模型：

- **移植到 26.1.2**：
  - 主模组与 JDTE-AE 基于 NeoForge 26.1.2.126、Java 25、Just Dire Things 1.6.11 和 AE2 26.1.13-beta 构建。
  - 流体、物品和能量传输改用 NeoForge 原生 transfer API。
  - 机器存档改用 `ValueInput`/`ValueOutput`。
  - 物品模型改用新版客户端物品定义。
- **用 Blockbench 重绘模型**：
  - 雷暴升级。
  - 带电引雷针：顶部铜制接口与上方放置的原版避雷针对齐，衔接连贯。
  - 大型温室、生命合成舱、大型矿物提取机（均为 3×3×2），沿用小型机器的蚀影合金、炽金和天界晶配色。
- **暂缺的联动**：
  - Botany Pots 与 Draconic Evolution 尚无 26.1.2 版本，暂不提供以下联动：
    - 温室盆栽作物。
    - 混沌守卫掉落。
    - 稳定刷怪笼与聚合能量。
  - 相关代码已保留，待上游发布后恢复。
  - Just Dyna Things 的 26.1.2 版本已移除回响芽块，晶体孵化器改为通过标签识别 JDT 时间芽块。
- 1.21.1 存档不保证可直接升级，升级前请先备份。

主模组与配套可选 JDTE-AE 统一为 **26.0.0**，客户端与服务端请使用相同版本。
