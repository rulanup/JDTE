# JDT Extras 0.6.2.0

Released October 3, 2026. This feature and maintenance release introduces the Bio Extractor machine series, Fluid Mixer GUI and recipe overhaul, multi-storage pagination for the Advanced Upgrade Storage, and dependency decoupling fixes for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.2.0.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.2.0.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.1.0 requires no configuration or world changes; machine settings and block entities carry over unchanged.

## Highlights

### Bio Extractor Series (`jdte:advanced_bio_extractor`, `jdte:extended_bio_extractor`)

- **Living Entity Product & Fluid Harvesting**: Machines consuming FE to automatically extract drops and fluids from living entities within range without killing them (e.g. cow milking directly into internal tanks, sheep shearing retaining fleece dye colors, chicken eggs, squid ink).
- **Entity Cooldown Tracking**: Tracks extraction cooldown per entity to prevent infinite instant harvesting, configurable via standard machine timing.
- **Ghost Filter Support**: Ghost spawn egg filtering with allowlist/denylist modes to specify exactly which mob types to harvest from.
- **Tier Progression**:
  - **Advanced Bio Extractor**: 4 upgrade slots, 1 output slot, 200,000 FE capacity, 8,000 mB fluid tank, base 3-block radius.
  - **Extended Bio Extractor**: 8 upgrade slots, 4 output slots, 400,000 FE capacity, 16,000 mB fluid tank, base 5-block radius.
  - Can be upgraded in-world using an Extended Upgrade card.

### Fluid Mixer Overhaul (`jdte:fluid_mixer`)

- **GUI Polish**: Completely redesigned machine layout featuring a dedicated, crisp progress arrow (`mixer_arrow.png`), top-centered catalyst slot at `(94, 14)` aligned with the arrow, fluid container slot, and explicit tooltips for Input Tank A, Input Tank B, and the Output Tank.
- **Recipe & Viewer Alignment**: Fully aligned JEI recipe viewer click areas and categories, plus complete Patchouli and GuideME guide book integration.

### Advanced Upgrade Storage Multi-Storage Pagination

- **Footer Paging**: When carrying multiple Advanced Upgrade Storages across player inventory and Curios slots, the docked machine side-panel displays interactive `[ < ]  X / Y  [ > ]` paging controls to quickly browse and toggle between all carried storages.
- **Cascading Shift-Click**: When Shift-clicking upgrades from machine upgrade slots back into storage, if the currently displayed storage becomes full, items automatically cascade into subsequent non-full storages.

### Ultimate Time Wand DYNA Decoupling

- **Decoupled Requirement**: Fixed an issue where the Ultimate Time Wand failed to function properly when JustDynaThings was not installed.
