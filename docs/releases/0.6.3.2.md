# JDT Extras 0.6.3.2

Released October 7, 2026. This feature and throughput release introduces the Advanced AE Output Upgrade with extreme batch extraction capability and expands single-slot product stacking in both the Greenhouse and Large Greenhouse to 6,400,000 under the Ultimate Capacity Upgrade, for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.3.2.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.3.2.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.3.1 requires no configuration or world changes; machine settings, inventories, and block entities carry over unchanged.

## Highlights

### Advanced AE Output Upgrade (`jdte:advanced_ae_output_upgrade`)

- **Extreme Extraction Capacity**: Designed for ultra-high-throughput automation setups where standard output upgrades cannot keep pace. Single-operation fluid extraction budget is expanded to `Integer.MAX_VALUE` (up from 64,000 mB), enabling complete drainage in one go.
- **1 Tick 10 Extractions ("1T 抽 10 次")**: Executes up to 10 extraction cycles per tick in server post-tick processing, ensuring that output buffers never bottleneck continuous high-speed production.
- **Interleaved Ultimate Overclock Flushing**: When installed on machines with the Ultimate Overclock Upgrade, AE output flushes are interleaved directly between internal execution cycles (1 tick / 10 executions). This clears buffers immediately before subsequent iterations execute, preventing full-inventory aborts.
- **Coalesced Machine Drainage**: Supported batch machines (`LootFabricatorBE`, `CrystalIncubatorBE`) invoke intermediate AE flushes during high-volume batch processing to maintain non-stop production.
- **Seamless AE2 Wireless Binding & Conflict Checks**: Binds to the AE2 network via Wireless Access Point (WAP) right-click. Mutually exclusive with the standard AE Output Upgrade to prevent duplicate overhead.

### Greenhouse & Large Greenhouse Stacking Expanded to 6,400,000

- **6.4 Million Item Slot Limit**: Installing the Ultimate Capacity Upgrade (`jdte:ultimate_capacity_upgrade`) now scales the output slot stack limit for both the Greenhouse (`jdte:greenhouse`) and Large Greenhouse (`jdte:large_greenhouse`) to **6,400,000** items per slot.
- **High-Rate Acceleration Match**: Fixes output bottlenecks under 32768X wand acceleration or Ultimate Overclock, providing massive internal buffer headroom for automated crop yields.
