# JDT Extras 0.6.4.0

Released October 12, 2026. This feature and maintenance release updates Fluid Mixer Time Fluid production and parallel processing, fixes Ultimate Time Wand entity-upgrade smithing and AE pattern compatibility, and expands Mineral Extractor output stacking, for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.4.0.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.4.0.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

This release requires no configuration or world migration.

## Highlights

### Fluid Mixer Time Fluid Recipe and Parallel Upgrades

- Time Fluid mixing now consumes water and one Time Fluid Catalyst instead of relying on the previous recipe inputs.
- The Mixing Parallel Upgrade allows up to 8 simultaneous operations.
- The Ultimate Mixing Parallel Upgrade allows up to 2,147,483,647 simultaneous operations. Actual throughput remains bounded by available ingredients, output capacity, and FE.

### Ultimate Time Wand Smithing and AE Pattern Compatibility

- Corrected the smithing recipe for applying the Entity Acceleration Upgrade to the Ultimate Time Wand.
- The recipe now exposes the expected template, base item, and addition inputs so AE crafting patterns can represent the transformation.

### Mineral Extractor Ultimate Capacity

- Under the Ultimate Capacity Upgrade, Mineral Extractor output slots can stack up to 6,400,000 items.
- Fixed mineral-cache handling so an empty lookup is represented and reused correctly.
