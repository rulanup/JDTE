# JDT Extras 0.6.1.0

Released October 1, 2026. This major feature release introduces Advanced Upgrade Storage with interactive machine panel docking, the Entity Acceleration Upgrade for the Ultimate Time Wand, and the Advanced and Extended Entity Accelerators for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.1.0.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.1.0.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.0.3 requires no configuration or world changes; machine settings and block entities carry over unchanged.

## Highlights

### Advanced Upgrade Storage (`jdte:advanced_upgrade_storage`)

- **Interactive In-Screen Machine Panel**: Carrying an Advanced Upgrade Storage in the player inventory or Curios slot automatically docks a live collapsible 6×6 upgrade panel onto the side of any opened JDT or JDTE machine interface (`BaseMachineScreen`).
- **Direct Machine Synchronization**: Allows 1-click and Shift-click transfers directly between the docked upgrade storage and the machine's upgrade slots, as well as cursor-held upgrade interactions.
- **6×6 Capacity (36 Slots)**: Up to 36 upgrade slots stacking up to 64 per slot, with anti-nesting protection and component persistence.
- **Curios Compatibility**: Fully wearable in Curios slots (`curios:curio`) with immediate screen integration.

### Entity Acceleration Upgrade (`jdte:entity_acceleration_upgrade`)

- **Ultimate Time Wand Smithing Upgrade**: Applied to the Ultimate Time Wand via smithing table or crafting grid to enable direct entity right-click acceleration.
- **AI & Movement Suppression**: During wand acceleration, target entity AI goals, navigation, and mob pushing collisions are automatically suspended to keep entities safely stationary while ticking.

### Entity Accelerators (`jdte:advanced_entity_accelerator`, `jdte:extended_entity_accelerator`)

- **Living Entity Acceleration**: Machines that consume JDT Time Fluid and FE to directly accelerate living entities (`LivingEntity`) in a configurable area.
- **AI & Movement Suppression**: During accelerated sub-ticks, entity AI pathfinding, navigation, and mob pushing collisions are suppressed, allowing biological ticks (growth, breeding, effects) to accelerate smoothly without erratic motion.
- **Ghost Filter & Player Exclusion**: Ghost spawn egg filtering with allowlist/denylist modes; players are automatically excluded from acceleration.
- **Advanced & Extended Tiers**: Advanced version supports 1-64x (128x overclocked, 4 upgrade slots); Extended version supports 1-512x (1024x overclocked, 8 upgrade slots) and higher entity throughput per tick. Can be upgraded in-world with an Extended Upgrade card.
