# JDT Extras 0.6.0.1

Released September 25, 2026. This is the naming and package-structure normalization release for the 0.6.0 line, for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.0.1.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.0.1.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.0 or 0.6.0-fix1 requires no configuration or world changes. Registry IDs, config field names, and config file names are untouched, so worlds, datapacks, and player configs stay fully compatible.

## Highlights

### Naming and package normalization

Event-driven classes now follow unified semantic suffixes: pure static NeoForge handlers end in `*Events`, stateful runtime subsystems in `*Manager`, stateless static utilities in `*Helper`, and input/IO processors in `*Handler`. `BioCrusherDropCapture` became `BioCrusherDropEvents`, `AEExtractionPlayerService` became `AEExtractionPlayerManager`, and `TimeMultitoolContinuousMiningClient` became `TimeMultitoolContinuousMiningEvents`.

The runtime managers (Advanced Item Collector, Entity Suppressor, Time Freezer, AE Output, Machine Output, Range Blocker, Extended Time Acceleration, and AE Extraction Player) moved out of `common/blockentities` into a dedicated `common/manager` package, together with `TimeAccelerationWorkQueue`; the block-entity package now holds only block entities and their direct collaborators. The JEI plugin tree and the Jade plugin moved under `client/`, matching the existing EMI plugin placement, because both are client-only optional-dependency code. Cross-package collaborators keep their contracts through widened public visibility with no behavior change.

The `jdte-ae` addon aligned on the uppercase `AE` abbreviation (`AeGridAccelerationBackend` → `AEGridAccelerationBackend` and siblings), so both modules share the same two-letter abbreviation style.

### Lang and resource cleanup

Screen translation keys are unified under the `jdte.screen.*` prefix (213 keys per language plus their call sites), replacing the reversed `screen.jdte.*` form. `en_us.json` no longer contains a stray Chinese character in the Life Synthesis Vat stats line, the Ultimate Time Wand entity name dropped its redundant "Entity" suffix in both languages, and the missing `entity.jdte.time_accelerator_effect` translation was added. `fluidbar.png` was renamed to `fluid_bar.png` to match the separated-word convention of every other GUI texture; the upstream Just Dire Things texture path is untouched. The mod description now reflects the actual feature set instead of "machine upgrade addon".

### Compatibility notes

`ICreativeGreenhouse` keeps its name because it is shared cross-mod API with the JDTE-Matrix addon. The `eclipsealloy_wrench` and `big_fluid_tank` registry IDs and the per-section config field names are grandfathered for save compatibility and documented in AGENTS.md. The full naming conventions are codified in the AGENTS.md "Naming conventions" section.
