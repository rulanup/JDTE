# JDT Extras 0.6.3.1

Released October 7, 2026. This performance and maintenance release optimizes JDTE machines for 32768X wand acceleration with a unified coalesced acceleration pipeline, resolves Crystal Incubator time acceleration, and adds Jade fluid capacity warnings for the Greenhouse and Large Greenhouse for Minecraft 1.21.1, NeoForge 21.1.216+, Just Dire Things 1.5.7+, and Java 21.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install the matching `jdte-0.6.3.1.jar` on the client and server. The optional full-grid addon is `jdte-ae-0.6.3.1.jar`; install matching JDTE and JDTE-AE versions on both sides when using full-grid AE2 acceleration. The `-sources.jar` files are for development and are not placed in the mods folder.

Upgrading from 0.6.3.0 requires no configuration or world changes; machine settings and block entities carry over unchanged.

## Highlights

### Native 32768X & Extreme Wand Acceleration Optimization

- **Coalesced Machine Acceleration (`CoalescedAcceleratedMachine`)**: Overhauled and expanded coalesced tick acceleration handling across all JDTE production and processing machines (Bio Crushers, Bio Extractors, Bio Factory, Fluid Mixer, Gel Generator, Infusion Machines, Life Breeder, Life Extractor, Loot Fabricator, Advanced Potion Brewer, and Crystal Incubator).
- **Lag-Free Extreme Speed**: When accelerated by extreme multipliers (up to 32768X from the Ultimate Time Wand), machines batch iterations, pre-validate FE and fluids, verify output inventory space, and smoothly flush accumulated ticks, eliminating micro-tick execution bottlenecks and client/server stutter.
- **Ultimate Overclock Synergy**: Machines equipped with an Ultimate Overclock Upgrade smoothly receive 1-tick / 10-iteration acceleration benefits without thread contention.

### Crystal Incubator Time Acceleration Fix

- **Scoped Anti-Nesting Marker**: Removed `TimeAcceleratorMachine` from `TimeAcceleratorBE` and isolated it strictly to true time accelerators (`BasicTimeAcceleratorBE`, `AdvancedTimeAcceleratorBE`, `ExtendedTimeAcceleratorBE`, and entity accelerators). This resolves an issue where the Crystal Incubator was rejected by time acceleration managers and time wands as a recursive accelerator.
- **Batch Crystal Growth & Harvest**: Integrated `CoalescedAcceleratedMachine` into `CrystalIncubatorBE`, supporting up to 64 cycles per tick of bounded growth checks and cluster harvesting with full output space validation, as well as a 10x multiplier boost when an Ultimate Overclock Upgrade is installed.

### Greenhouse & Large Greenhouse Jade Fluid Warning

- **Actionable In-Game Feedback**: When a Greenhouse or Large Greenhouse has an Ultimate Overclock Upgrade installed but lacks sufficient capacity upgrades, Jade displays a clear warning status explaining that internal Time Fluid capacity is too low to sustain accelerated operation.
