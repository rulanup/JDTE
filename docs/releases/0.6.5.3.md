# JDT Extras 0.6.5.3

Adds the Ultimate Essence Conversion Upgrade (`jdte:ultimate_essence_conversion_upgrade`) with up to 2,147,483,647 bound Crafting Patterns, smithing upgrade preserving bound patterns, and improved Greenhouse rotation handling.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install `jdte-0.6.5.3.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.5.3.jar`; use matching JDTE and JDTE-AE versions on both sides with AE2 19.2.17 or newer in the 19.x series. The `-sources.jar` files are for development. SHA-256 checksums are included in `SHA256SUMS-0.6.5.3.txt`.

## Ultimate Essence Conversion Upgrade

- **Bound pattern capacity**: Supports up to 2,147,483,647 bound Crafting Patterns.
- **Crafting**: Upgraded in a smithing table using Netherite Upgrade Smithing Template + Advanced Essence Conversion Upgrade + Time Crystal (`jdte:time_crystal`). Any patterns already bound to the advanced card are preserved.
- **Limits**: Shares `UpgradeType.ESSENCE_CONVERSION` and the one-card limit per Greenhouse / Large Greenhouse with the normal and advanced versions.
- **Rotation & Tooltips**: Handles rotation with arbitrary numbers of bound patterns, safely indexing shared ingredient cycles. Tooltips summarize overflow when bound patterns exceed display limits.

## 中文说明

新增**顶级精华转化升级**（`jdte:ultimate_essence_conversion_upgrade`）：

- **样板容量**：支持绑定至多 2,147,483,647 个合成样板。
- **制作方式**：在锻造台中使用**下界合金升级锻造模板 + 高级精华转化升级 + 时间水晶**升级制作，保留已有绑定样板。
- **机器限制**：与普通版、高级版共享 `ESSENCE_CONVERSION` 类别，每台普通温室或大型温室最多安装 1 张。
- **轮转与提示**：支持任意数量样板的安全轮转；样板列表超出界面显示上限时显示折叠数量提示。

主模组与配套可选 JDTE-AE 均更新为 **0.6.5.3**，客户端与服务端请使用匹配版本。
