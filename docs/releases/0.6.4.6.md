# JDT Extras 0.6.4.6

Released October 17, 2026. Updates the Ultimate Time Wand texture and preserves its previous appearance in the optional legacy resource pack.

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install `jdte-0.6.4.6.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.4.6.jar`; use matching JDTE and JDTE-AE versions on both sides with AE2 19.2.17 or newer in the 19.x series. The `-sources.jar` files are for development. SHA-256 checksums are included in `SHA256SUMS-0.6.4.6.txt`.

## Ultimate Time Wand texture

- Installed the supplied 16×16 RGBA PNG for `jdte:ultimate_time_wand` without modifying its image data.
- The item model references `jdte:item/ultimate_time_wand` and retains the vanilla handheld display transforms used by the previous JDT model.
- Added an embedded copy of the previous JDT wand texture and its handheld item model to the optional legacy pack. All earlier pack contents are retained.

## Refreshing the legacy resource pack

Client startup exports the pack to `resourcepacks/JDTE-Legacy-Textures.zip`. An existing file is preserved. To update an exported pack, back it up, remove the old file, and restart the client. Enable the newly exported pack in the Resource Packs screen to restore the old appearance.

The supplied PNG bytes, image format, model references and legacy ZIP integrity were checked. In-game appearance has not been verified.
