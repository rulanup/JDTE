# JDT Extras 0.6.5.2

Clarifies the Mineral Extractor's optional fluid bonuses in machine tooltips, JEI, configuration help and bilingual guides following [issue #24](https://github.com/rulanup/JDTE/issues/24).

## Compatibility and installation

| Component | Requirement |
| --- | --- |
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.216 or newer |
| Just Dire Things | 1.5.7 or newer |
| Java | 21 |

Install `jdte-0.6.5.2.jar` on the client and server. The optional full-grid AE2 addon is `jdte-ae-0.6.5.2.jar`; use matching JDTE and JDTE-AE versions on both sides with AE2 19.2.17 or newer in the 19.x series. The `-sources.jar` files are for development. SHA-256 checksums are included in `SHA256SUMS-0.6.5.2.txt`.

## Mineral Extractor resource guidance

Both the standard and Large Mineral Extractors use these rules:

| Resource | Role under default settings |
| --- | --- |
| FE | Base 1x production uses 5,000 FE per batch; JDT's Smelter Upgrade doubles that cost. |
| Fortune fluid, normally Experience Fluid | Optional bonus yield. A boosted batch consumes 25 mB and gains +100% yield. Without it, normal yield remains available. |
| Acceleration fluid, normally Time Fluid | Pays for extra accelerated batches at 5 mB per batch. Base 1x batches do not consume it. |

- Machine and JEI fluid tooltips now explicitly identify the optional bonuses and state that base 1x production needs only FE.
- English and Chinese GuideME/Patchouli pages describe normal yield and base-speed operation with empty fluid tanks.
- Configuration help explains both fluid roles and the free corresponding bonus when a fluid cost is set to zero. Creative upgrades waive the corresponding costs.
- Regression coverage verifies base production without either fluid bonus and the explanatory tank tooltips. During development, all 39 targeted mineral production, fluid routing, GUI and recipe tests passed.

## 中文说明

根据 [#24](https://github.com/rulanup/JDTE/issues/24) 的反馈，补充普通与大型矿物提取机的资源说明：

- **基础 1x 生产只需 FE**：默认每批 5,000 FE，安装 JDT 烧炼升级后每批 10,000 FE。
- **经验流体用于可选的时运增产**：默认获得加成的批次消耗 25 mB，产率提高 100%；不供应时仍可按普通产率生产。
- **时间流体用于额外加速批次**：默认每个额外批次消耗 5 mB，基础 1x 批次不消耗。
- 在机器与 JEI 的流体提示中明确标注可选用途，并同步中英文 GuideME/Patchouli 指南和配置说明。创造升级或流体消耗配置为 0 时免除相应消耗。
- 补充基础产量和提示文字的回归测试；开发阶段 **39 项相关测试全部通过**。

主模组与配套可选 JDTE-AE 均更新为 **0.6.5.2**，客户端与服务端请使用匹配版本。
