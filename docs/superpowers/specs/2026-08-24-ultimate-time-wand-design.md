# 顶级时间手杖设计规格

## 目标

新增 `jdte:ultimate_time_wand`，复刻 Just Dyna Things 高级时间手杖的操作方式，但由 JDTE 独立实现，不导入、继承或调用 Dyna 的任何类。

顶级时间手杖沿用 Dyna 的容量默认值，并将最高模式提升到 1024×：

| 项目 | 默认值 |
| --- | ---: |
| 时间流体容量 | 800,000 mB |
| FE 容量 | 10,000,000 FE |
| Normal 模式 | 2× |
| 2× 模式 | 4× |
| 4× 模式 | 16× |
| Max 模式 | 1024× |

容量、基础时间流体成本、基础 FE 成本和各模式步进均进入 JDTE 配置，默认值保持上述行为。

## 操作逻辑

### 模式切换

手杖在物品数据组件中保存模式：`normal`、`x2`、`x4`、`max`。默认模式为 `normal`。

潜行右键时循环切换模式，并发送当前模式提示；模式循环顺序为 Normal → 2× → 4× → Max → Normal。模式对应的内部时间指数为 `1`、`2`、`4`、`10`，加速倍率由 `2^指数` 得出，因此 Max 为 1024×。

### 方块操作

普通右键方块时，服务端执行以下流程：

1. 校验目标是否为 JDT 时间手杖允许的加速目标，或是否包含可用 AE2 `IGridTickable` 服务。
2. 查找目标位置已有的 JDTE 时间手杖实体。
3. 没有实体时，按当前模式创建一个持续 600 个真实 tick 的实体。
4. 已有实体时，将实体指数增加当前模式的步进，最大不超过指数 `10`，并按 Dyna 逻辑补充已消耗时间的一半。
5. 按最终指数计算本次时间流体和 FE 成本；资源不足、目标无效或实体已达到最高指数时，不创建、不修改实体，也不消耗资源。
6. 成功后扣除资源、播放对应音调，并同步实体数据。

目标方块右键专用于时间手杖操作；时间流体通过标准 `FluidContainingItem` 能力和现有容器/管道路径填充，不改变 Dyna 的模式切换语义。

### 实体生命周期

新增 `UltimateTimeWandEntity`，由 JDTE 自己注册和保存以下状态：

- 目标方块坐标；
- 时间指数；
- 总剩余时间和当前剩余时间。

实体在服务端每个真实 tick 检查目标和剩余时间。目标失效、剩余时间耗尽或维度卸载时实体移除。客户端只接收同步状态并渲染倍率和剩余时间，不执行加速逻辑。

实体保留 Dyna 的叠加语义：再次点击已有实体时，指数按模式步进增加，剩余时间按已消耗时间的一半补充；指数达到 `10` 后不再重复收费或修改实体。

## 加速执行与 AE2

### 普通目标

将时间手杖实体的目标执行接入 JDTE 的共享时间加速目标执行器，复用 JDT 有效目标判断、随机刻处理、无效目标清理和 JDTE 的执行预算。达到 1024× 时，超出当前 tick 预算的工作进入待执行队列，不丢弃已支付的工作，也不在单个真实 tick 中无界循环。

普通目标执行 JDT 的标准额外 tick 逻辑；如果目标同时被识别为 AE2 网格目标，不再重复执行普通方块实体 tick。

### AE2 目标

只在 AE2 已加载且目标位置存在公开的 `IGridTickable` 服务时进入 AE2 路径。调用 JDTE 已有的公共 AE2 集成，通过 `IGridTickable.tickingRequest(node, 1)` 逐步执行请求，并移除返回 `SLEEP` 的端点。

顶级时间手杖直接启用 AE2 路径，不需要 `AE_ACCELERATION_UPGRADE`。没有 AE2、没有网格节点或节点没有 `IGridTickable` 服务时，目标按普通 JDT 目标处理。新增代码只依赖 AE2 的公开 API，不依赖 Dyna 的可选类。

AE2 目标和普通目标使用相同的执行预算、失效清理和待执行工作结算，避免同一个目标在一次请求中被重复加速。

## 资源与安全

- FE 成本沿用 JDT 时间手杖的倍率成本公式，并使用饱和整数乘法。
- 时间流体成本沿用 JDT 时间手杖的倍率成本公式，保留小数结算，避免高倍率下因逐次取整产生免费操作。
- 创造模式免除资源消耗，但仍执行目标有效性和实体状态校验。
- 所有资源模拟、实体创建、实体修改和资源扣除都只在服务端执行。
- 右键失败时不生成实体、不延长实体、不扣除任何资源。
- 实体状态保存使用稳定的 NBT 键，重启后能恢复目标位置、指数和剩余时间。

## 代码结构

- `UltimateTimeWandItem`：物品注册、模式切换、右键目标和资源扣除。
- `UltimateTimeWandEntity`：服务端生命周期、状态同步和目标提交。
- `UltimateTimeWandTargetRuntime`：普通目标与 AE2 目标的统一路由，避免重复 tick。
- `UltimateTimeWandRenderer`：复用现有时间加速效果的可视信息，显示倍率和剩余时间。
- `UltimateTimeWandData`：模式、倍率、成本和指数边界的纯逻辑方法。

现有 `TimeAcceleratorBE`、`ExtendedTimeAccelerationManager` 和 `ExtendedTimeAcceleratorAE2Integration` 只做必要的共享入口抽取，不改变现有机器的升级卡规则和运行语义。

## 注册与资源

- 注册 `jdte:ultimate_time_wand` 物品和对应实体类型；
- 注册模式数据组件、客户端实体渲染器和创造模式物品；
- 增加中文/英文名称、模型属性、配方和 GuideME 条目；
- 配方使用 JDTE 现有高阶材料，不引用 Dyna 物品；
- 不修改 Dyna 可选集成类，不让未安装 Dyna 的环境出现类加载依赖。

## 测试与验收

单元测试覆盖：

- 模式循环、指数到倍率、1024× 上限和非法模式恢复；
- 容量、成本、饱和乘法和小数流体结算边界；
- 新建实体、叠加实体、最高指数、资源不足和目标无效时的状态变化；
- NBT 保存/加载和客户端同步字段；
- AE2 服务存在、服务休眠、AE2 未加载以及普通目标回退；
- 源码和编译检查确认新增手杖不引用 Dyna 包。

验收命令：

```text
./gradlew test
./gradlew compileJava
```

手动验收使用未安装 Dyna 的配置测试普通 JDT 目标，使用安装 AE2 的配置测试 AE2 设备，并确认潜行右键切换模式、普通右键叠加倍率、资源不足不扣除，以及 Max 模式达到 1024×。

## 非目标

- 不替换 JDT 原版 `time_wand`；
- 不修改 Dyna 的物品、实体或配置；
- 不让普通 JDT 时间手杖获得直接 AE 加速；
- 不把 AE2 加速卡的能力扩展到其他机器；
- 不新增 Curios 槽位或便携装备逻辑。
