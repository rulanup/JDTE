# 大型燃料罐

<ItemImage id="jdte:large_fuel_canister" scale="2" />

大型燃料罐把 JDT 燃料罐扩展到 **40,000,000** 燃料上限，并保持与原版燃料罐相同的使用方式。

## 燃烧规则

- 单次最小消耗按原版规则放大到 **10 倍**。
- 燃烧倍率按原版燃料解析结果放大 **10 倍**。
- JDT 发电机和大型便携发电机会按解析后的大型倍率工作。
