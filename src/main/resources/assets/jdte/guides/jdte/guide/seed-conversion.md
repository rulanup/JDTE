# Seed Conversion

Install one Seed Conversion Upgrade in a Greenhouse or Large Greenhouse. It replaces newly harvested drops of the planted seed with the crop's primary Mystical Agriculture essence, one item for one item. Other drops and the reusable planted templates remain intact.

Only a primary output in the Mystical Agriculture essence tag enables conversion. Ordinary crops keep their seeds. Previously stored seeds are not converted retroactively. The converted quantities are included in output-capacity checks before a harvest is committed.

Seed Conversion can be installed alongside either Essence Conversion tier. Seed replacement runs first, and the resulting essence can feed an automatic or recorded conversion recipe before adjacent or AE output. The installed card persists with the machine and is accepted by upgrade storage and the settings copier under the normal upgrade rules.

The crafting recipe is enabled only when Mystical Agriculture is installed.
