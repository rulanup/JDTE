# Large Fuel Canister

<ItemImage id="jdte:large_fuel_canister" scale="2" />

The Large Fuel Canister expands the JDT fuel canister to a **40,000,000** fuel cap while preserving the same general handling pattern.

## Burn rules

- Minimum single-use fuel consumption is scaled up by **10x**.
- Burn speed multiplier is scaled up by **10x** from the base resolved fuel-canister value.
- Both the normal JDT generator and the large pocket generator use that resolved large-canister multiplier.
