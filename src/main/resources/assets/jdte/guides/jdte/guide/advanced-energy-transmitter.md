# 高级能量传输器

<BlockImage id="jdte:advanced_energy_transmitter" scale="2" />

高级能量传输器会向配置范围内所有可接收 FE 的方块实体供能，并提供 8 个标准升级槽。

| 项目 | 默认行为 |
|------|----------|
| 内部容量 | 2,000,000,000 FE |
| 初始范围 | 传输器上方一格（X/Y/Z 半径为 0，Y 偏移为 1） |
| 目标刷新 | 完成扫描后等待 20 tick 再开始下一轮 |
| 扫描预算 | 每服务端 tick 检查 512 个方块位置 |
| 目标预算 | 每次操作最多尝试 512 个缓存目标 |
| 基础传输预算 | 每次操作 268,435,456 FE；超频后 8 倍，最高受整数上限约束 |
| 支持升级 | 范围、过滤、容量、超频、创造 |

## 工作方式

机器把“发现目标”和“传输能量”分成两个独立阶段。目标范围按固定预算分批扫描，扫描期间继续使用上一轮完整缓存供能；新一轮扫描完成后才原子替换目标列表，因此扩大范围不会造成单 tick 全范围扫描，也不会在刷新期间中断已有目标。

传输使用循环游标公平轮询缓存目标。已满、失效或暂时不能接收能量的目标同样计入每次尝试预算，避免大量异常目标拖慢服务端。机器优先使用目标朝向传输器的一面，若该面不接收 FE，再检查其他方向。默认排除其他高级能量传输器，防止互相充能形成循环。

过滤器按目标方块物品匹配。白名单、黑名单和 NBT 比较设置变化后会立即丢弃旧缓存并开始新扫描；范围或机器朝向变化也会触发重建。范围内未加载的区块不会被强制加载，后续刷新时会自动发现已经加载的目标。

## 升级与界面

- **范围**：提高半径和偏移上限。
- **过滤**：增加可用过滤槽。
- **容量**：扩大内部 FE 缓冲。
- **超频**：缩短传输操作间隔，并将总传输预算和 ME 取电预算提高到配置倍率。
- **创造**：无需内部 FE 即可持续供能，并包含超频效果。

每次操作先在固定目标预算内模拟并汇总真实缺口，再从能量物品槽和可用 ME 能源中批量补充，最后每个目标只执行一次实际接收。该流程不会提高范围扫描频率或目标尝试次数。

安装 AE2 与应用通量（Applied Flux）后，普通 ME 线缆可直接连接传输器任意一面。传输器占用一个频道，并通过公开 ME 存储 API 从能源磁盘中的 FE 按需取电；每次普通方块供能操作最多执行一次批量 ME 提取，不扫描磁盘或存储单元。网络断电、缺少频道或任一模组缺失时会直接停用 ME 取电，普通 FE 输入仍可使用。GUI 与 Jade 均会显示 ME 集成状态；内部缓存为 0 不代表离线，因为 ME 能量可以按需直供。

匹配 NBT 按钮右侧的玩家按钮可将传输器绑定到当前操作者。绑定后，设备区块处于加载状态且玩家在线时，可跨维度、跨距离优先为该玩家的快捷栏、主副手、护甲和 Curios 饰品中的 FE 装备充能。玩家装备通道不占用方块扫描或目标尝试预算，并使用独立的装备数与单装备调用上限控制成本。首次绑定后，仅绑定玩家或创造模式管理员可解除绑定。

粒子按钮控制从传输器飞向成功方块目标的能量流显示，不影响供能；单次粒子目标数有独立服务端预算。

能量容量、操作间隔、刷新间隔、扫描数量、尝试目标数量、总传输预算、超频倍率、ME 取电预算、单目标传输上限、玩家装备检查/调用上限、传输器循环排除和粒子预算均可在 `jdte.advancedEnergyTransmitter` 配置分类中调整。
