# 时间定格器

<BlockImage id="jdte:time_freezer" scale="2" />

时间定格器消耗时间流体来冻结所在维度的昼夜时间和天气，是服务器管理员用于掌控世界时间节奏的自动化设备。

## 功能

- **定格时间**：激活期间世界的昼夜时间被固定在定格瞬间，太阳与月亮不再移动。
- **定格天气**：在主世界激活时，当时的天气状态（晴/雨/雷）会被固定，不再自然变化或切换。
- **消耗时间流体**：每 Tick 消耗 100 mB 时间流体（可在配置中调整）。流体耗尽后自动停止定格。
- **红石控制**：支持忽略信号、高电平、低电平和脉冲四种模式，默认忽略信号（总是工作）。
- **升级槽**：时间定格器提供 4 个标准升级槽；扩展时间定格器提供 8 个。容量与流体升级增加流体储量，创造升级免除流体消耗。

## 使用方式

- 通过管道或桶向机器输入时间流体（只接受时间流体）。
- 多台时间定格器可以同时工作，它们共享同一个冻结目标，不会互相跳变；任意维度都有自己独立的冻结时间。
- 拆除时会保留机器内的流体（方块实体数据）。

## 管理指令

服务端管理员（权限等级 4）可以使用：

```
/jdte timefreezer list
```

列出服务器上所有已加载的时间定格器，包括所在维度、坐标、当前是否在定格，以及剩余时间流体。坐标可点击直接传送，便于定位被遗忘的机器。

扩展时间定格器可以使用扩展升级卡在时间定格器上右键转换而来，获得 8 个升级槽。
