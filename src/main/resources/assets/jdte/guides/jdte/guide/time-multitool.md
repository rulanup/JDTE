# 时间多功能工具

<ItemImage id="jdte:time_multitool" scale="2" />

时间多功能工具以蚀空合金多功能工具为基础，不用切换模式即可承担镐、铲、斧和锄的工作，并兼容 JDT 原版工具升级。

## 能源与工具动作

工具可以储存 **500,000 FE**。破坏方块和执行工具动作都需要足够的单次破坏 FE；电量不足时，挖掘速度退回手挖速度，耕地、去皮等动作也不会执行。

普通右键方块会按目标选择合适动作，例如把泥土或草方块耕成耕地、给原木去皮。潜行右键方块打开 JDT 工具能力设置界面。

## 点击与连续挖掘

短按攻击键保持在首次瞄准的方块；按住达到默认 **250 毫秒** 后，可以连续转向后续方块。松开按键后立即停止并重置下一次点击，键位重新绑定后同样生效。

等待时间位于客户端配置 `jdte/time-accelerator-local.toml` 的 `jdte.timeMultitool.continuousMiningHoldDelayMillis`，可在主菜单配置中调整；设为 `200` 或 `300` 可改变手感，`0` 恢复立即连续挖掘。已主动启用的 JDT 范围挖掘能力仍按其原有规则工作。

工具支持原版 **时运** 与 **精准采集** 附魔的适用标签，可使用附魔书；两者保持原版互斥规则。

## 时间流体速度

工具还可以储存 **1000 B（1,000,000 mB）时间流体**。潜行右键空气会依次切换六档速度：

| 档位 | 每个成功破坏方块的时间流体消耗 |
|---|---:|
| 1x | 0 mB |
| 2x | 2 mB |
| 4x | 4 mB |
| 16x | 16 mB |
| 256x | 256 mB |
| 1024x | 1024 mB |

安装锤击、连锁砍树等批量能力时，工具会在开始前按整批目标检查时间流体。流体不足会让整批回落到 1x，不会让第一个方块先获得高倍速度后免除消耗；FE 仍按 JDT 的工具规则逐次检查，只有实际成功移除的方块才结算时间流体。
