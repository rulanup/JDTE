# 充能避雷针

在雷暴期间供电，避雷针每 200 刻消耗 10,000 FE 产生一次闪电。安装雷暴升级后，晴天也能运行。超频模式每刻最多产生 5 次闪电，终极超频每刻最多 50 次。可在机器界面分别调整闪电显示和声音。

闪电落在机器顶部的铜触点。安装 AE2 Lightning Tech 时，请留空机器上方一格，机器会在那里安装该模组识别雷击配方所需的原版避雷针。
