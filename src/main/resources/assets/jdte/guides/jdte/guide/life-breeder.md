# 生命繁育器

<BlockImage id="jdte:life_breeder" scale="2" />

生命繁育器在设定范围内繁殖动物或村民，并直接推进幼体成长与成年繁殖冷却。它使用生物原本的繁殖逻辑，不复制父母 NBT，也不会重复运行完整实体 AI。

## 快速使用

1. 设置工作范围和模式。
2. 在 2x2 输入槽放入范围内生物所需的繁殖食物。
3. 输入 FE 和生命流体，然后选择 `1-32x` 速度。
4. 机器会把范围内已有的鸡蛋等物品实体收进 4x2 输出槽；放不下的物品保留在世界中。

## 模式

| 模式 | 行为 |
|------|------|
| 繁殖与成长 | 自动配对，同时推进幼体成长和成年冷却 |
| 仅繁殖 | 只繁殖当前可配对的成年生物 |
| 仅成长 | 不消耗饲料繁殖，只推进成长与冷却 |

村民每对需要 24 点食物，例如 6 个面包或 24 个胡萝卜、马铃薯、甜菜根，也可以混用；不要求额外空床。

## 消耗与升级

- 生命流体按实际跳过的生物 Tick 计算；默认成长 20 Tick 消耗 10 mB，每次繁殖约消耗 3000 mB。
- 超频升级会直接结算本轮处理对象的剩余幼年期或繁殖冷却，并按实际跳过时间收费。
- 创造升级包含超频效果，并免除 FE 与生命流体。
- 支持容量、流体、范围、过滤、超频和创造升级，以及红石控制和绝对方向自动 I/O。
- 过滤槽放刷怪蛋指定实体类型；白名单只处理列出类型，黑名单排除列出类型，空过滤允许全部兼容生物。

## 兼容与限制

- 使用 Minecraft 标准 `Animal`、`AgeableMob` 繁殖与成长接口的模组生物会自动兼容；性别、品种和遗传规则仍由生物自身决定。
- 村民使用独立公开 API 适配；完全自定义且不使用标准体系的实体不会被强制繁殖。
- 机器只查询已加载区块，并对扫描、配对、成长和物品回收设置独立预算。
- 同种生物默认达到 64 只后停止继续繁殖，避免无限增长；预算与消耗均可在服务端配置。
