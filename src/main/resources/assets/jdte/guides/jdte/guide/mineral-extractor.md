# 矿物提取机

<BlockImage id="jdte:mineral_extractor" scale="2" />

矿物提取机根据群系的标准矿石世界生成配置，按归一化估算权重直接生产矿石方块。机器只查询服务器在数据包加载时构建的矿物索引，不扫描区块，也不会生成新区块。

## 矿物清单

1. 手持空白矿物清单，在目标群系中右键记录矿物分布。
2. 右键已记录清单可查看矿物、估算概率、高度、矿脉规模和识别可信度。
3. 将清单放入机器左侧槽位后，机器使用清单群系；未放入已记录清单时，使用机器当前位置的群系。

数据包重载改变矿物索引后，旧清单会标记为过期并停止生产。请在目标群系重新记录，避免配置变化后继续使用旧权重。

## 生产与资源

| 项目 | 默认行为 |
|------|----------|
| 基础处理 | 每 20 Tick 累计 1 批，默认每 20 Tick 合并结算 |
| 能量 | 每批 5,000 FE |
| 经验流体 | 每批 25 mB，使该批产率提高 100%；不足时其余批次保持普通产率 |
| 时间流体 | 仅加速批次消耗，每批 5 mB；基础 1x 批次不消耗 |
| 速度 | 普通可调 1-32x；超频或创造升级固定为 1024x |
| 输出 | 基础 16 格；每张容量升级增加 16 格，最多 64 格 |

机器在结算前模拟完整输出。输出不足、能量不足、无候选矿物或清单过期时不会扣除本次资源，也不会丢出物品。高倍率工作使用批量权重结算，耗时随矿物种类数增长，而不是逐次执行 1024 个生产循环。

## 过滤与自动化

- 支持容量、流体、过滤、超频和创造升级。
- 黑白名单匹配最终矿石方块；过滤后会重新归一化剩余矿物权重。
- 自动 I/O 和管道可输入矿物清单、经验流体、时间流体和 FE，并从分页输出槽提取产物。
- 自定义世界生成 Feature 无法自动识别时，整合包可通过 `data/<namespace>/jdte/mineral_sources/*.json` 提供矿物来源覆盖。
