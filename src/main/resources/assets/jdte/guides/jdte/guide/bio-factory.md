# 生物工厂

<BlockImage id="jdte:bio_factory" scale="2" />

生物工厂使用可重复利用的刷怪蛋或资源蜜蜂笼作为样本，将材料、流体和 FE 转化为生物产物。舱内生物仅为客户端展示，不会生成或 Tick 真实实体。

## 快速使用

1. 在样本槽放入刷怪蛋或装有蜜蜂的笼子。
2. 按 JEI 配方在下面 3 个无序材料槽放入食物、授粉物或消耗材料。
3. 输入 FE；生命流体提高产量，时间流体启用速度调节，培养流体用于流体授粉配方。
4. 物品与产物流体从各自输出通道取出。

## 槽位与资源

| 区域 | 用途 |
|------|------|
| 1 个样本槽 | 可复用刷怪蛋或蜜蜂笼 |
| 3 个材料槽 | 无顺序；是否消耗由配方决定 |
| 8 个输出槽 | 每张容量升级增加 8 格，最多 32 格 |
| 生命流体 | 足量时默认使本轮产量变为 2 倍 |
| 时间流体 | 启用 `1-32x`，超频或创造升级为 64x |
| 培养/产物流体 | 前者用于配方输入，后者独立输出牛奶等产物 |

机器具有固定 5 倍基础工作速率，但不会增加单轮消耗。只有产物能够完整写入时才扣除 FE、流体和消耗材料；缺少生命或时间流体时仍可按基础产量和速度运行。

## 配方兼容

- 内置常见动物产物、16 色羊毛、蜂蜜脾、雪球、蛙明灯、山羊角、可疑炖菜、猫礼物和熊猫黏液球等配方。
- 整合包可通过 `jdte:bio_factory` 添加最多 3 项无序材料；`count: 0` 表示可复用，大于 0 才会消耗。
- Productive Bees 样本使用当前加载的高级蜂箱产出、准确授粉物/流体、环境条件与产量基因。
- Alpha、Beta、Gamma、Omega 产量升级共用 4 张上限；Omega 可产出蜜脾块。
- JDTE 生命流体蜜蜂以高级或扩展生命提取器授粉，生命蜜脾可离心得到生命流体与蜂蜡。

JEI 会显示实际输入、概率产物、流体、FE 和处理时间。

## 升级与自动化

- 支持容量、流体、超频、创造及配方允许的专用升级。
- 内置 JDTE 配方最多接受 4 张抢夺升级；Productive Bees 动态配方不受抢夺影响。
- 创造升级包含超频效果并免除机器资源消耗。
- 自动 I/O 将三类输入流体和产物流体隔离，避免输入管道抽走流体产物。
