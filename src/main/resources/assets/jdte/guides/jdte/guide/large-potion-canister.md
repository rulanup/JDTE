# 大型药水罐

<ItemImage id="jdte:large_potion_canister" scale="2" />

大型药水罐是 JDT 药水罐的扩展版本，容量提升到 **4,000 mB**。

## 批量灌装规则

- 每次必须放入 **4 瓶相同药水**。
- 成功后增加 **1,000 mB**。
- 仅有 3 瓶或混合药水时不会消耗输入。
