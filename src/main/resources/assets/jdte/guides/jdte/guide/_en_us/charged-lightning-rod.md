# Charged Lightning Rod

Supply power during a thunderstorm to produce one strike every 200 ticks for 10,000 FE. Install a Thunderstorm Upgrade to operate in clear weather. Overclock allows up to five strikes per tick and Ultimate Overclock allows up to fifty. The machine screen has separate controls for rendering and sound.

Lightning strikes the copper contact on top of the machine. With AE2 Lightning Tech installed, leave one block of air above it so the machine can install the vanilla lightning rod that its strike recipes require.
