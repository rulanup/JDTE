# 工厂打包机

<BlockImage id="jdte:factory_packer" scale="2" />

工厂打包机把选区中的方块、方块实体、非玩家实体和计划 Tick 保存进便携包裹，并在其他位置完整恢复。库存、能量、流体和大多数模组数据会随方块实体保存。

## 打包

1. 用范围界面或蚀空合金扳手选择区域；打包机本身必须位于选区外。
2. 放入空工厂包裹并点击开始。
3. 等待扫描、存档、权限检查和分批剪切完成。
4. 完成后的包裹会显示尺寸、方块数和根实体数。

## 放置

1. 手持包裹查看真实方块预览；右键固定位置，Shift 右键清除位置。
2. 按住范围调节键（默认左 Alt）滚轮，以 90° 步进旋转。
3. 确保完整目标区域为空，把包裹放入目标打包机并开始。
4. 成功恢复方块、实体和计划 Tick 后，包裹才会被消耗。

未固定位置时使用打包机范围原点。运行期间包裹、范围、旋转和机器方块都会锁定；失败操作会回滚，安全落盘的任务可在服务器重启后继续。

## 限制与安全

- 黑名单方块、未加载区块或超出配置上限的选区会拒绝启动；聊天栏会报告问题方块与坐标。
- Mekanism 裂变反应堆必须完整框选。机器会先停堆并等待燃烧结束，恢复后保持关闭，需检查冷却和废料通路再手动启动。
- 内部绝对坐标、方块朝向、实体位置和 JDT 范围偏移会随旋转转换。
- AE2、Mekanism、物流网络等已实现公开搬运适配；没有公开接口、仅存在未知全局管理器中的私有状态无法保证迁移。
- 玩家和跨维度区块票不会被打包。

## 范围与升级

| 项目 | 默认值 |
|------|--------|
| X/Y/Z 半径 | 10；范围升级提高到 20/40 |
| 单轴/总体积上限 | 128 格 / 1,000,000 格 |
| 处理预算 | 每 Tick 512 项；超频或创造升级为 4 倍 |

支持范围、容量、超频和创造升级；创造升级同时免除 FE。压缩存档和预览读取在 I/O 线程执行，避免长时间阻塞服务器 Tick。
